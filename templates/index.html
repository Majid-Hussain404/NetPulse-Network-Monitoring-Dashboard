📖 Networking Concepts

🌐 DNS Resolution

Domain Name System (DNS) translates human-readable domain names like google.com into machine-readable IP addresses like 142.250.195.46. Think of it as the internet's phone book. Without DNS, you would have to memorize numbers for every website.

⏱️ Latency

Latency (or response time) is the time it takes for a data packet to travel from your computer to a server and back — measured in milliseconds (ms). Lower latency means a faster, more responsive connection. Latency above 200 ms is generally noticeable.

🔗 TCP Connectivity

TCP (Transmission Control Protocol) ensures reliable, ordered delivery of data. When NetPulse checks a host, it attempts a TCP handshake on port 80 (HTTP) or 443 (HTTPS). If the handshake completes, the host is reachable. If it times out, the host is unreachable or a firewall is blocking the connection.

🛡️ Ports

A port is a numbered endpoint on a server. Common ports include 80 (HTTP), 443 (HTTPS), and 22 (SSH). NetPulse tries port 80 first, then falls back to 443, mimicking how a web browser connects.
